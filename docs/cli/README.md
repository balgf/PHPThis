# Application CLI knowledge index

Use this index when a task concerns an operational application command, scheduled pass, application-owned migration command, or the optional local environment launcher that hands off to one of those commands. Read [the complete CLI and scheduler guide](../cli.md), ADR 025, [ADR 028](../decisions/028-application-owned-redis-cache-and-schedule-lease.md) for the executable example's Redis lease, and [ADR 043](../decisions/043-engine-specific-application-migration-invariants.md) when migration work applies; read [ADR 027](../decisions/027-application-owned-explicit-sqlite-migrations.md) only for the SQLite reference proof. For local configuration delivery, read [Application-owned local environment launcher](../configuration/local-environment-launcher.md). These smaller pages route an AI to the relevant invariant without inventing a framework console or launcher.

- [Arguments and output](arguments-output.md): sole entrypoint, finite job, scheduler, and migration commands, optional launcher handoff, bounded arguments, exit codes, stream bytes, and redaction.
- [Scheduling and coordination](scheduling-locking.md): explicit UTC cadence, one-pass work, the example's application-private Redis owner-token lease, and known non-deduplication and fencing limits; continual job consumption instead follows [externally supervised one-shot operations](../jobs/operations.md).
- [Composition](composition.md): immutable configuration shared between fresh HTTP, CLI, and migration graphs without a container or mutable request state, with an optional launcher ending before application composition.
- [Testing](testing.md): universal real-console failure, redaction, and resource-bound evidence; optional real-launcher evidence; time and overlap evidence only for scheduled passes; and separate migration-history and writer-coordination evidence under ADR 043.

All pages describe application-owned patterns. The checked launcher is an ordinary application-owned PHP file invoked through explicit PHP CLI, not a framework command. Framework `bin/phpthis` remains the installed checker. PHPThis adds no core command, registry, parser, local environment launcher, dotenv loader, configuration cache, scheduler, clock, lock, lease, migration, schema, daemon, process manager, discovery, or distributed-coordination API.
