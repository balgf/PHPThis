# Guardrails

The backend-neutral jobs structure proof removes one required verifier module and requires exact redacted failure without a native path-bearing warning, restores the module, pins the exact reference's scoped error-handler restoration and absence of broad suppression, and executes the named `composer jobs:verify` command directly before proving its transitive complete-gate route. This remains structure-only evidence under `NOT_APPLICABLE(JOBS)` and `REFERENCE_ONLY(JOBS_VERIFICATION_STRUCTURE)`.

`php tools/guardrails.php` currently enforces repository-level invariants without third-party packages. The entrypoint explicitly loads five concern modules in one fixed order: repository, context, boundaries, operations, and distribution. Each module exposes one narrowly named failure function, retains its concern-owned marker maps and controls, and returns every failure to the entrypoint for one deterministic aggregate result. There is no module discovery, rule registry, container, configuration language, shared content cache, or package/runtime integration.
