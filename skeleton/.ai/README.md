# Application context index

`AGENTS.md` owns the current task router, universal rules and completion workflow. `.ai/project.md` owns product vocabulary, invariants and accountable roles; first contributors read it and the applicable architecture/context records before implementation. Keep application facts committed and free of secrets.

The installed `vendor/phpthis/framework/docs/consumer-contract.md` remains the minimum contract. Read it for installation, deliberate context adoption, upgrades or conflicts. Existing applications keep their owned instructions until an explicit adoption reconciles stronger local rules and unresolved decisions; installing a package does not replace them.

For an upgrade, read `vendor/phpthis/framework/docs/consumer-contract-upgrades.md#contract-version-18`. The complete `vendor/phpthis/framework/docs/consumer-contract-upgrades.md` is historical context. Use `vendor/phpthis/framework/docs/knowledge-map.md` for an unknown framework concern.
