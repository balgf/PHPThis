# Application durable-job contract

`NOT_APPLICABLE(JOBS)`: the health-only starter performs no deferred work and has no job table, outbox, broker, envelope, publisher, relay, consumer, worker, lease, acknowledgement, retry, redrive, dead letter, supervisor, jobs verification script or external side effect.

Before adopting jobs, read installed `vendor/phpthis/framework/docs/jobs/README.md`. Accepted ADR 052 supplies the optional backend-neutral contract and verification structure. Replace this statement only after an accountable human selects and records the exact backend, client, topology, security, publication/recovery, envelope, dispatch, delivery ordering/concurrency and ownership-window/liveness, effect, retry/terminal, privileged-operation, lifecycle, operations, redaction and real-service evidence decisions. The canonical application evidence script is `jobs:verify`, wired through `test` into `check`; it is not a runtime command or PHPThis checker API and must fail closed without required real-service evidence.

The current accepted checked profile remains installed `vendor/phpthis/framework/docs/jobs/sqlite.md` under ADR 024. Adopt it only deliberately and preserve its exact SQLite-specific transaction, lease, one-shot lifecycle, retry, dead-letter, idempotency and evidence boundaries. Do not introduce a queue abstraction, adapter, backend checker, worker or speculative dependency. Never claim cross-system atomicity or exactly-once execution or effects.
