# Application change workflow

`AGENTS.md` owns the completion workflow and task router. Use the selected guide before implementation, name behavior and side effects, add meaningful tests, update application facts and run `composer check`.

Database setup starts with `.ai/configuration.md` and its installed scope contract before external action. External values use installed `vendor/phpthis/framework/docs/type-safety.md`; record representation, bounds, normalization, failure classification and evidence in `.ai/architecture.md`. Adopted migration structure stays in `.ai/migrations.md`. `.ai/testing.md` owns test infrastructure and the complete application gate.

An explanation follows the same evidence route and cites current files without changing them.
