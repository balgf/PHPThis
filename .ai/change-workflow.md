# Maintainer change workflow

Follow the completion workflow in `AGENTS.md`: name behavior and side effects, write meaningful evidence, implement the direct change, update its documentation owner, and run the complete `composer check` gate. `.ai/testing.md` owns test infrastructure; concern guides own their evidence requirements.

For database setup, start with `.ai/configuration.md` before external action. For release operations, follow `RELEASING.md`. Accepted decisions already made for the task remain effective.
