# Common-change calibration v1

This is a six-run operational calibration, separate from the sixty-trial [comparison protocol](comparison-v1.md). It cannot supply framework correctness rates or replace a failed comparison attempt. It uses revision 2 of the same three task fixtures and private holdouts, once under each condition, in the comparison's first-round order.

Each fresh run requests `gpt-5.4-2026-03-05`, high reasoning, and standard service. Its explicit execution override allows 200,000 cumulative input/output tokens, 1,200 seconds, 4 MiB output, and no post-scoring repair. The host enforces a maximum USD 1.00 token charge per run, hence USD 6.00 across the six predeclared starts. Model input remains below the 272,000-token pricing tier. The fixed dated rates are $2.50 per million input, $0.25 cached input, and $15 output. These are API token-charge limits under the recorded prices, not a guarantee about taxes, unrelated account use, or future provider pricing. [Official prices](https://developers.openai.com/api/docs/pricing).

The proxy uses integer units: one dollar is 100,000,000 units, and each token costs its cents-per-million rate in those units. Before dispatch it reserves the complete counted input at the uncached rate plus the maximum permitted output. Both the token and monetary remainder bound that output; insufficient allowance for the counted input and sixteen output tokens rejects before creation. Only validated terminal usage settles the reservation. Validated cached input earns its exact discount; missing cached usage is conservatively priced as uncached. Reasoning is part of output, not an additional charge. An ambiguous response retains its monetary and token reservations and stops the calibration.

Originally, the candidate received the original functional prompt followed by one fixed budget-and-working-instructions suffix. Newly prepared runs insert the [versioned workspace policy block](../agent-evaluation-controller/README.md#prepare-and-preflight) between that source and the unchanged suffix; historical runs keep their frozen implementation and prompt. The suffix, effective budgets, and spending policy have a separate identity. The source task manifest and original prompt remain unchanged and are retained alongside the effective prompt. Required authority, protected files, edit limits, public checks, private scoring, and OCI isolation remain in force. The calibration-only compaction threshold is 200,001 tokens so this bounded run cannot enter an unreviewed compaction operation. The old comparison and smoke arguments remain unchanged.

Use `calibration-prepare`, `calibration-run`, and `calibration-report` with one exact configuration. It has the comparison preparation fields plus the fixed `calibration` policy, shared profile condition `calibration-v1`, six-run approval, and a USD 6.00 ceiling. Preparation validates all six source/dependency/lock/installed-document/holdout bindings without a credential or model call. Execution uses the same host proxy and OCI lifecycle. Its distinct `agent-evaluation-calibrations/<id>/` directory retains a new implementation snapshot, all plans before generation, starts, terminal records, scores, and hash-bound evidence. An existing identity cannot be reused. No automatic retry, resume, replacement, or private-feedback repair is allowed.

Calibration attempts, scores, and reports use distinct kind markers and do not validate as comparison-v2 records. Reports recompute automated checks from retained evidence, preserve unknown usage, and never publish comparative rates or invent human review. Failed generation may retain no exported patch; absence of a patch does not prove the candidate made no edit. Use retained events to report only observed progress, and leave unobserved work unknown.

The calibration asks whether these instructions and allowances let the agent reach an edit, finish generation, and pass the application and private checks. A completed six-run calibration is operational evidence; a subsequent full study still needs its own frozen design, affordable spending allocation, all predeclared attempts, and accountable review. The historical five campaigns and unresolved reservations remain recorded separately.
