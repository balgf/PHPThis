# Data contract

Use SQLite through pdo_sqlite with JSON1 support. The observation driver owns a new scratch database for each request, fixed schema creation and seed data; no migration or external database is adopted. Tables are memberships(principal_id,account_id), documents(id,account_id,document_key,title,category,private_note), events(id,document_id,event_type), and outbox(id,document_id,job_type). Document keys are unique per account. Runtime work uses only the injected connection; setup and independent durable observation are excluded from its query trace. All data values are bound. Query structure is code-owned. Reads must enforce both requested/resolved account and current actor membership. Existing rows must survive failed writes unchanged. Transaction lifetime belongs to the operation. No cache, replica, schema ownership model, grant system or background worker is adopted.
