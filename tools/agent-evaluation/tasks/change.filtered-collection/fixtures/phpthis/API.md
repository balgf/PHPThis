## Filtered document collection

`GET /accounts/{account_id}/documents` accepts only optional `category` and `after_id` query keys and no body. Category is a nonempty string of at most64 UTF-8 bytes, valid UTF-8 without ASCII control or DEL bytes. Lists, booleans, null, empty/oversized text and unknown keys fail400. Ordinary punctuation is valid literal category data. `after_id` is a string containing a canonical positive decimal integer within PHP's integer range; leading zeros, lists and overflow fail400.

Select only documents in the requested/resolved account when the principal has current membership. Omitted category selects all categories; a supplied category selects exact equal values. Return documents with `id > after_id`, or from the beginning when absent. Order by ascending integer id. Return at most20 records and use a lookahead to decide whether another matching record exists. Return200 with exactly `{"data":[{"id":1,"title":"Example","category":"general","event_count":0}],"meta":{"next_after_id":null}}`. `next_after_id` is the integer id of the last returned record only when another matching record exists; otherwise null. Counts include only that document's events. Empty or inaccessible selections return an empty data array and null cursor. Reads make no durable changes.
